## Detailed Description

Shows a colored message box positioned above the associated control.
Automatically repositions when the form layout changes. Temporary
messages auto-dismiss after 4 seconds.

<div class="admonition note">

**Note:** This is an internal component used by the JASP framework.
Module developers do not need to use this directly.
