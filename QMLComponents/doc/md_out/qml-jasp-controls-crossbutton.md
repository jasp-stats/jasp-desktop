# CrossButton QML Type

An internal × (cross) button used to dismiss or remove items.


|                   |                            |
|-------------------|----------------------------|
| Import Statement: | `import JASP.Controls 1.0` |


- [List of all members, including inherited
  members](qml-jasp-controls-crossbutton-members.md)

## Detailed Description

Renders two rotated rectangles forming an × icon. Thickens on hover for
visual feedback. Used internally by
[ControlErrorMessage](qml-jasp-controls-controlerrormessage.md) and other components.


**Note:** This is an internal component. Module developers do not need
to use this directly.


## Signals

- **crossClicked()** - Emitted when the cross button is clicked.
