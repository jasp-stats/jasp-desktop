## Detailed Description

<div class="admonition note">

**Note:** This is an internal UI component. Module developers do not use
this control directly. It renders a small colored overlay tag showing
the keyboard shortcut key for each focusable control when ALT navigation
mode is active.

</div>

## Properties

- **tagText** (string) - The shortcut key character displayed in the
  tag.
- **active** (bool) - Whether the tag is currently visible. Default:
  false.
