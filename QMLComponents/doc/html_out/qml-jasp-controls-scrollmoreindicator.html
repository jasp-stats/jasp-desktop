    ScrollMoreIndicator QML Type

    An internal gradient shadow indicating more content is available by scrolling. More...

    Import Statement: import JASP.Controls 1.0
    • List of all members, including inherited members

    Detailed Description

    Displays a directional gradient overlay at the edge of scrollable areas to hint that more content exists beyond the visible bounds.

    Note: This is an internal component. Module developers do not need to use this directly.
