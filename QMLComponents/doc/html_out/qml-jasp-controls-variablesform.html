    VariablesForm QML Type

    A two-column layout with available variables on the left and assigned lists on the right. More...

    Import Statement: import JASP.Controls 1.0
    • List of all members, including inherited members

    Detailed Description

    Creates a form where an AvailableVariablesList and one or more AssignedVariablesList are connected. It creates automatically the Arrow buttons for each AssignedVariablesList and sets their height to fill the form.

    Note: VariablesForm does not bind directly to R options. The child VariablesList controls each have their own R binding.

    Properties

    • listWidth (int) - Width of each variable list. Default: width * 2 / 5.
    • removeInvisibles (bool) - Remove invisible controls from the layout. Default: false.

    Example

    VariablesForm {
    AvailableVariablesList { name: "allVariables" }
    AssignedVariablesList { name: "dependent"; title: qsTr("Dependent Variable"); singleVariable: true }
    AssignedVariablesList { name: "fixedFactors"; title: qsTr("Fixed Factors"); allowedColumns: ["nominal"] }
}
