JASP.Controls QML Module

This module contains all the visual elements used to build JASP analyses.

Core Controls

  • CheckBox - Boolean toggle control
  • DropDown - Selection dropdown
  • TextField - Text input field
  • VariablesList - Variable selection list
  • Group - Layout container

ALTNavTag

Internal tag displayed during ALT keyboard navigation

AddColumnField

A text input field that creates a new computed column in the dataset

AllowedTypeIcons

Internal component that displays variable type filter icons

AssignButton

Internal arrow button for moving variables between source and target lists

AssignedPairsVariablesList

A variable list preset for paired variable assignment

AssignedRepeatedMeasuresCells

A variable list preset for assigning variables to repeated measures cells

AssignedVariablesList

A variable list preset for assigned variable selection

AvailableVariablesList

Source list showing all available dataset variables

BasicThreeButtonTableView

A table input control with Add, Delete, and Reset buttons

BayesFactorType

A pre-built radio button group for selecting Bayes Factor reporting format

Button

A generic clickable button

CIField

A percentage input field preset for confidence interval width

CheckBox

A boolean toggle control that binds a true/false value to an R option

DropDown

A selection control that presents a list of options in a dropdown menu

Group

A layout container that groups related controls together

TextField

A single-line text input control for entering strings

VariablesList

Primary variable selection control in JASP
