JASP.Controls QML Module

This module contains all the visual elements used to build JASP analyses.

The complete list of types is automatically generated below.

AddColumnField

A text input field that creates a new computed column in the dataset

AllowedTypeIcons

Internal component that displays variable type filter icons

AssignButton

Internal arrow button for moving variables between source and target lists

AssignedPairsVariablesList

A variable list preset for paired variable assignment

AssignedRepeatedMeasuresCells

A variable list preset for assigning variables to repeated measures cells

AssignedVariablesList

A variable list preset for assigned variable selection

AvailableVariablesList

Source list showing all available dataset variables

BasicThreeButtonTableView

A table input control with Add, Delete, and Reset buttons

BayesFactorType

A pre-built radio button group for selecting Bayes Factor reporting format

Button

A generic clickable button

CIField

A percentage input field preset for confidence interval width

CheckBox

A boolean toggle control that binds a true/false value to an R option

CheckColumnIsFreeOrMineField

A text field that validates whether a column name is free or owned by the current analysis

Chi2TestTableView

A table view preset for entering multinomial chi-squared hypotheses

ColorPalette

A dropdown preset for selecting a color palette for plots

ColumnLayout

A vertical layout container with JASP-themed spacing

ComponentsList

A dynamic list that repeats a user-defined component for each row

ComputedColumnField

A text field for entering a computed column name

ContrastsList

A composite control for specifying contrasts for factor variables

ControlErrorMessage

An internal popup that displays validation errors or warnings above a control

CustomContrastsTableView

A table view preset for entering custom contrast weight matrices

Divider

A horizontal line separator with an optional centered label

DoubleField

A text field preset for entering numeric (double) values

DropDown

A selection control that presents a list of options in a dropdown menu

FactorLevelList

A grid editor for defining factors and their levels

FactorsForm

A form for defining latent factors by assigning observed variables

FactorsList

An assigned variables list with an editable title, used for individual factor panels

FileSelector

A text field with a browse button for selecting files or directories

Form

Top-level container for an analysis input form

FormulaField

A text field preset for entering R-style formulas

GridLayout

A responsive grid layout with JASP-themed spacing

Group

A layout container that groups related controls together

InputListView

An editable scrollable list for entering free-text values

IntegerField

A text field preset for entering integer values

JAGSTextArea

A text area preset for writing JAGS model code

JagsTableView

A table view preset for entering JAGS data

Label

A JASP-themed text label

ModelTermsList

A preset VariablesList for building ANOVA model terms

PercentField

A numeric field preset for entering percentage values (0–100)

RadioButton

A radio button option within a RadioButtonGroup

RadioButtonGroup

A group of mutually exclusive radio button options

RowLayout

A horizontal layout with JASP-themed spacing

Section

A collapsible panel that groups child controls under a clickable header

SetSeed

A preset "Repeatability" group with a seed checkbox and integer field

SimpleTableView

A table view preset with Add Column, Delete Column, and Reset buttons

Slider

A slider with a linked numeric text field

SubjectivePriors

A preset "Prior" section with default and informed prior distribution options

Switch

A toggle switch control

TabView

A tabbed container that manages dynamic panels

TableView

A scrollable, editable data table for entering structured values

Text

A JASP-themed text display element

TextArea

A multi-line text input with optional line numbers and syntax highlighting

TextField

A single-line text input control for entering strings

VariablesForm

A two-column layout with available variables on the left and assigned lists on the right

VariablesList

Primary variable selection control in JASP
