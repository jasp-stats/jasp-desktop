    CIField QML Type

    A percentage input field preset for confidence interval width. More...

    Import Statement: import JASP.Controls 1.0
    Inherits:

    PercentField

    • List of all members, including inherited members

    Detailed Description

    Extends PercentField with defaults suitable for confidence interval input: 95% default value, 1 decimal place, and exclusive bounds (0-100 not included).

    R Binding

    • R Type: numeric
    • Default: 95

    Properties

    • name (string) - R option name this control binds to. Default: "".
    • label (string) - Label displayed before the field. Default: "".
    • defaultValue (var) - Default percentage value. Default: 95.
    • decimals (int) - Number of decimal places. Default: 1.

    Inherited Properties

    • enabled (bool) - Whether the control is interactive. Default: true.
    • visible (bool) - Whether the control is visible. Default: true.
    • info (string) - Info that will be used by tooltip and to generate the help. Default: "".
    • toolTip (string) - This property overwrite info property, in order to display a simpler tooltip text. Default: "".

    Example

    CheckBox {
    name: "includeCI"
    label: qsTr("Confidence interval")

    CIField {
        name: "ciWidth"
    }
}
