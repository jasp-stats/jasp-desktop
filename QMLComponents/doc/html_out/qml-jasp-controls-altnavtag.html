    ALTNavTag QML Type

    Internal tag displayed during ALT keyboard navigation. More...

    Import Statement: import JASP.Controls 1.0
    • List of all members, including inherited members

    Detailed Description

    Note: This is an internal UI component. Module developers do not use this control directly. It renders a small colored overlay tag showing the keyboard shortcut key for each focusable control when ALT navigation mode is active.

    Properties

    • tagText (string) - The shortcut key character displayed in the tag.
    • active (bool) - Whether the tag is currently visible. Default: false.
