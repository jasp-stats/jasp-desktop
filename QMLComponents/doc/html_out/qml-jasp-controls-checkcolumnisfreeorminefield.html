    CheckColumnIsFreeOrMineField QML Type

    A text field that validates whether a column name is free or owned by the current analysis. More...

    Import Statement: import JASP.Controls 1.0
    Inherits:

    TextField

    • List of all members, including inherited members

    Detailed Description

    Extends TextField with the "checkColumn" input type, which ensures the entered column name is either not yet used in the dataset or already belongs to the current analysis. Typically used when an analysis creates or claims a computed column.

    R Binding

    • R Type: character
    • Default: ""
