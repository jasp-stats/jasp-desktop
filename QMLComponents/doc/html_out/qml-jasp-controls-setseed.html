    SetSeed QML Type

    A preset "Repeatability" group with a seed checkbox and integer field. More...

    Import Statement: import JASP.Controls 1.0
    Inherits:

    Group

    • List of all members, including inherited members

    Detailed Description

    Provides a standardized Group titled "Repeatability" containing a "Set seed" CheckBox with an IntegerField for the seed value. Drop this into any analysis that uses random sampling.

    R Binding

    • R Options:
      • setSeed (bool) — Whether seeding is enabled
      • seed (integer) — The seed value
