    ControlErrorMessage QML Type

    An internal popup that displays validation errors or warnings above a control. More...

    Import Statement: import JASP.Controls 1.0
    • List of all members, including inherited members

    Detailed Description

    Shows a colored message box positioned above the associated control. Automatically repositions when the form layout changes. Temporary messages auto-dismiss after 4 seconds.

    Note: This is an internal component used by the JASP framework. Module developers do not need to use this directly.
